# Jagadish Gosala — portfolio

Static site: `index.html` + `resume.pdf`. No build step, no dependencies.

## Deploy (Vercel)
1. Push this repo to GitHub.
2. Vercel → Add New → Project → import the repo → Framework preset: **Other** → Deploy.
3. Settings → Domains → add your domain.

Every push to `main` redeploys automatically.

## Update the resume
Replace `resume.pdf` and push.
